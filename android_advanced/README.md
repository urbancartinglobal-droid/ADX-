# ADX AI Assistant

Advanced Android build of ADX.

## Build

The repository includes a GitHub Actions workflow that installs Android SDK 35 and builds a debug APK.

## App permissions

The app may request microphone, notification-listener, and accessibility access depending on the enabled features. Grant only the permissions you are comfortable using.

## API key

Do not commit a Gemini API key into the repository. Enter credentials through the app's supported UI when prompted.
